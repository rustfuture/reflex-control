Check the work before your AI agent calls it done.

01 / THE WORKFLOW

Three checkpoints.
One agent turn.

Hooks add checks around an agent's actions. Your configured rules determine what is protected and which tests count as verification.

Set boundaries for file changes.

Check supported file writes against configured protected paths. The default policy includes environment files, private keys, and secrets directories.

Illustrative checkpointWrite → .envDenied → protected path

Hook behavior varies by agent. These checks are not a sandbox. Read the adapter coverage and limitations ↗

A released prototype.
A trace you can inspect.

The next proposed feature is optional Claude API analysis of user-selected code diffs and test-failure evidence: explain the issue and suggest concrete next steps.

The existing Claude Code hooks and this proposed API feature are separate. Content selection and sensitive-data handling need implementation and evaluation before user trials.
